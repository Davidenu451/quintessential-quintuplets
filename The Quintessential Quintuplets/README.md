# 🎌 The Quintessential Quintuplets - Premium Anime Website

Una celebrazione premium delle cinque sorelle Nakano con design dark luxury, animazioni cinematiche e interattività avanzata.

## ✨ Features

### 🎬 Cinematic Intro
- Video intro full-screen generato via AI (Sora)
- Mostra tutte le cinque sorelle Nakano
- Auto-hide dopo completamento con opzione di timeout

### 👭 Characters Gallery
- Card interattive con hover 3D effects
- Colori signature per ogni sorella
- Link diretti alle loro pagine biografiche

### 📖 Story Timeline
- Timeline animato della storia principale
- 4 tappe principali della narrativa
- Effetti glassmorphism premium

### 🔮 Hidden Easter Eggs
- Secret mode attivabile
- Particle effects e glow animations
- Interazioni nascoste nel sito

### 🎨 Premium Design
- 3 temi switchabili: Noir, Luxe, Rose
- Glassmorphism UI elements
- Dark luxury aesthetic
- Animazioni scroll-triggered

### 🎵 Audio Features
- Toggle audio con stile premium
- Persist preferenze con localStorage
